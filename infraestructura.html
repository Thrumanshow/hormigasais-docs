Sobre la operación
Pregunta Respuesta
¿Quién mantiene el protocolo? Cristhiam Leonardo Hernández Quiñonez (CLHQ) — desarrollador único, San Miguel, El Salvador.
¿"Sin servidores" significa qué? Sin servidor propio centralizado. El sitio y la API corren sobre GitHub Pages y Cloudflare — infraestructura pública de terceros, no infraestructura privada de HormigasAIS.
¿Los sellos tienen valor legal? Son evidencia criptográfica verificable (hash + HMAC + timestamp). No equivalen a una firma electrónica certificada bajo la Ley de Firma Electrónica de El Salvador, ya que HormigasAIS no está acreditado como Proveedor de Servicios de Certificación.
¿Cómo reporto una vulnerabilidad? Escribe a clhq@hormigasais.com con el asunto "Seguridad".
